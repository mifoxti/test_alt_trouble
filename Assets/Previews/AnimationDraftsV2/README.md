# Анимационные превью v2 — на согласование

Это только 8-кадровые черновики движения. Они не подключены к NPC и не используются игрой до вашего утверждения.

| Существо | Кадры | Скорость цикла | Движение |
|---|---:|---:|---|
| Сухокорень | 8 | 16 тиков/кадр (около 2,13 с на цикл) | Дыхание всего тела; крона, мох, лоза и два веера корней движутся с небольшим рассогласованием. |
| Свечная моль | 8 | 6 тиков/кадр (около 0,8 с на цикл) | Крылья бьют независимо; брюшко движется против фазы взмаха; голова, усики, лапки и свечное свечение тоже меняют положение/яркость. Для размаха добавлено прозрачное поле вокруг прежнего силуэта 40×32. |
| Пустой паломник | 8 | 18 тиков/кадр (около 2,4 с на цикл) | Медленный перенос веса вокруг опёртого посоха; покачиваются весь силуэт, капюшон и плащ; кончик шарфа запаздывает, глаза кратко загораются. |

PNG листы кадров и GIF-петли можно пересоздать из корня репозитория:

```powershell
python -m pip install Pillow
python Tools/AssetGeneration/generate_animation_drafts_v2.py
```
