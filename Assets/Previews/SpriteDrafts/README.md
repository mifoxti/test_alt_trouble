# Пиксельные черновики v1

Это native-size кандидаты для утверждённых концептов. Фон прозрачный, сглаживание не применялось.

| Файл | Размер | Назначение |
|---|---:|---|
| `WitheredRoot_32x30.png` | 32×30 px | Сухокорень, основной спрайт для дальнейших кадров |
| `CandleMoth_24x18.png` | 24×18 px | Свечная моль, основной спрайт |
| `HollowPilgrim_24x40.png` | 24×40 px | Пустой паломник, основной спрайт |
| `DormantEternalAltar_48x32.png` | 48×32 px | Дремлющий Алтарь, 3×2 тайла |
| `PixelSpriteDrafts_ContactSheet.png` | 8× preview | Сравнительный лист, nearest-neighbor |

Это спрайт-кандидаты для согласования, не анимационные листы и не текстуры мода. Для интеграции нужны отдельное одобрение этого пиксельного масштаба, после чего будут подготовлены кадры анимаций.
