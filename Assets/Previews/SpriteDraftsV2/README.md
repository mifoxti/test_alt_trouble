# Пиксельные черновики v2

Вариант переработан по детализированному концепт-листу мобов, который пользователь отметил как удачный. В отличие от первого прохода, сохранены крупные характерные детали и увеличен native-size:

| Файл | Размер | Что сохранено из концепта |
|---|---:|---|
| `WitheredRoot_v2.png` | 64×48 px | разветвлённые корни, мох, красная лоза, светящиеся глаза |
| `CandleMoth_v2.png` | 40×32 px | узорчатые крылья, рожки, свеча и янтарное брюшко |
| `HollowPilgrim_v2.png` | 64×64 px | глубокий капюшон, многослойный шарф, посох, фонарь и реликвии |

Фон спрайтов прозрачный, увеличение листа предпросмотра — nearest-neighbor. Это всё ещё черновики для согласования; в игровое содержимое они не подключены. Следующий художественный этап начнётся после подтверждения native-size.

Источник-концепт: `Assets/Source/Concepts/CursedGrove_Enemies_DetailedGuide.png`.

Повторная генерация из корня репозитория:

```powershell
python -m pip install Pillow
python Tools/AssetGeneration/generate_pixel_sprite_drafts_v2.py
```
