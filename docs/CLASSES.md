# Class mechanics

## Occultist

Occultist is an independent damage class built around preparation, ritual control, and Corruption. The initial resource model tracks Corruption from 0 to a configurable maximum. At a configurable danger threshold, Corruption imposes a defense penalty. Rituals and glyphs will add Corruption; a cleansing item or action will reduce it.

Planned mechanics: temporary ritual candles, Triangle of Binding, Pentagram of Sorrow, Wound, Binding, and Renunciation glyphs.

## Specter

Specter is an independent damage class built around phasing, delayed echoes, and Soul Fracture. The initial resource model tracks Ethereality, regeneration, phase duration, and cooldown. The phase state does not yet change collision or grant immunity; those combat rules will be implemented and tested with the phase mechanic.

Planned mechanics: a bounded Phase Shift, non-recursive Spectral Echo, and Soul Fracture with a controlled boss interaction.
