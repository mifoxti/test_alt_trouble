# Asset pipeline

Gameplay sprites and animation sheets will be produced by reproducible source scripts in `Tools/AssetGeneration`. Generator source, palette definitions, output dimensions, and frame layouts belong in Git so every PNG can be regenerated.

The planned art uses Terraria-scale pixel grids, transparent PNGs, nearest-neighbor scaling, and a shared dark fantasy/horror palette. The Blind Confessor, Weeping Seraph, resource indicators, and animation sequences require owner approval before final sprite generation. Preview sheets will show frame grids and timing before the assets are wired into gameplay.

Owner-approved direction and mandatory review stages are documented in [Animation direction](ANIMATION_DIRECTION.md). Read it before creating or changing character sprites, motion, or projectile visuals.
